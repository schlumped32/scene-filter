## Scene Filter, version 6

The first public release. Scene Filter finds nudity in a movie file you own, shows you exactly when it happens, and can make a filtered copy. Everything runs on your own computer: nothing is uploaded.

### Download
- **Mac:** `Scene_Filter_for_Mac.zip`
- **Windows:** `Scene_Filter_for_Windows.zip`

Unzip it and follow the "How to open" file inside. The first launch takes a few minutes to set up and needs an internet connection (about 700 MB).

### What it does
- **Two-stage scan:** a quick pass over the whole movie, then a close double-check of each suspicious moment with a more accurate detector, to cut down on false alarms and catch brief scenes
- **Animated movie switch:** cartoons can fool the detector, so this only flags confident, repeated matches
- **You stay in control:** review every flagged scene (with blurred previews) and untick any you want left alone
- **Filter options:** cut the scenes out, blur the screen, or black it out, with optional muting
- **Timestamp lists:** CSV, text, and a Kodi skip file, with no changes to the movie
- **Fast on modern computers:** parallel scanning, plus the hardware video encoders on Mac (Apple), and on Windows (NVIDIA, Intel, AMD)

### Automatic updates
From this version on, Scene Filter checks for updates each time it opens and installs them on its own. If an update ever fails to start, it automatically goes back to the previous version.

### Good to know
- No detector is perfect. Review the flagged scenes before relying on the result, especially for a movie you haven't seen.
- It only looks for visible nudity. Language, violence and suggestive scenes without nudity aren't detected.
- Use it only with movie files you have the right to use. Scene Filter doesn't read discs or remove copy protection.

Detection uses NudeNet (AGPL-3.0). Video processing uses FFmpeg.
