## Scene Filter, version 7

### Fixed
- **Windows: the Scene Filter window no longer flashes and disappears.** If something goes wrong when it starts, the window now stays open and explains what happened. If it was opened from inside the zip file (the most common cause), it says how to fix it: right-click the zip, choose **Extract All...**, and open Scene Filter from the extracted folder.
- **Windows:** everything the Scene Filter window shows is also saved to a log file (`%LOCALAPPDATA%\Scene Filter\scene-filter.log`), to help sort out problems.

Windows users: please download `Scene_Filter_for_Windows.zip` again to get this fix. Mac copies update themselves; nothing else changes on Mac.
